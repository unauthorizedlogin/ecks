# 🎬 Media & Videos

This directory contains **standalone videos showcasing the ecks RPG Framework**.

These videos are separate from the regular development documentation and devlog history. They are intended to provide focused demonstrations of specific systems, workflows, milestones, and framework capabilities.

Videos may include:

* System demonstrations
* Feature showcases
* Architecture walkthroughs
* Data-driven workflow demonstrations
* Framework trailers and promotional showcases
* Other focused presentations of the project

## Featured Videos

### 🎞️ ecks RPG — Data-Driven Systems Trailer

A focused showcase of the framework's data-driven architecture, following the complete pipeline from **CSV authoring → generated `.tres` resources → databases → runtime gameplay**.

The video demonstrates the ability system and effect pipeline, shows multiple damage types being driven through the same Effect System, and concludes with the standardized generator and database directory structures used throughout the framework.
